# 🦸‍♂️ GUÍA DE CONTRIBUCIÓN ÉPICA

¡Bienvenido, valiente contribuidor! Estás a punto de unirte a la **revolución galáctica del código**. Sigue estos pasos para convertirte en una leyenda:

## 🌟 **ANTES DE EMPEZAR**

1. **Lee el README** - Conoce el proyecto como la palma de tu mano estelar
2. **Revisa los Issues** - Quizá alguien ya está trabajando en tu idea
3. **Consulta el Roadmap** - En el README principal, mira hacia dónde vamos

## 🛠️ **PROCESO DE DESARROLLO**

### Para Nuevos Héroes 👶
```bash
# 1. Clona el repositorio
git clone https://github.com/tu-usuario/proyecto-galactico.git

# 2. Instala dependencias
npm install

# 3. Corre en modo desarrollo
npm run dev
```

### Para Características Épicas ⚡
1. Crea una rama desde `main`:
   ```bash
   git checkout -b feature/nombre-epico
   ```

2. Codifica como si el universo dependiera de ello 💻

3. Sigue nuestras convenciones:
   - **Commits**: Usa [Conventional Commits](https://www.conventionalcommits.org/)
   - **Código**: Sigue el estilo existente (es hermoso, ¿no?)
   - **Testing**: Añade tests para tus superpoderes nuevos

## 🧪 **PRUEBAS DE FUERZA GALÁCTICA**

Antes de enviar tu PR, ejecuta:
```bash
# Pruebas unitarias
npm test

# Pruebas de integración
npm run test:integration

# Linter (mantén el código brillante)
npm run lint

# Build (asegúrate que todo compile)
npm run build
```

## 📬 **ENVÍO DE PULL REQUEST**

1. **Actualiza tu rama** con los últimos cambios de `main`
2. **Asegúrate** que todas las pruebas pasen
3. **Actualiza la documentación** si es necesario
4. **Crea el PR** con:
   - Título descriptivo y épico
   - Descripción detallada de los cambios
   - Capturas de pantalla si es UI/UX
   - Referencia a Issues relacionados

## 📝 **PLANTILLA DE PULL REQUEST**

```markdown
## 🚀 ¿Qué hace este PR?

[Descripción clara y épica de los cambios]

## 🧪 ¿Cómo se probó?

- [ ] Pruebas unitarias
- [ ] Pruebas de integración
- [ ] Pruebas manuales
- [ ] Pruebas en navegadores múltiples

## 📸 Capturas de pantalla (si aplica)

## 🎯 Checklist

- [ ] El código sigue el estilo del proyecto
- [ ] Se añadieron pruebas
- [ ] La documentación se actualizó
- [ ] Los commits siguen conventional commits

## 🔗 Issues relacionados

Closes #123
```

## 🏆 **TIPO DE CONTRIBUCIONES QUE AMAMOS**

- **🐛 Reporte de bugs**: Claro, reproducible, con pasos para replicar
- **💡 Nuevas características**: Alineadas con la visión galáctica
- **📚 Mejoras de documentación**: Más clara, más épica
- **🎨 Mejoras de UI/UX**: Que hagan llorar de belleza
- **⚡ Optimizaciones**: Más rápido que la velocidad de la luz

## 🚫 **COSAS QUE NO HACEMOS**

- Características que rompen la compatibilidad sin discusión
- Cambios de estilo solo por gusto personal
- "Refactors" masivos sin aprobación previa

## 🤝 **CÓDIGO DE CONDUCTA**

Sé excelente con los demás. Discute ideas, no personas. Ayuda a los nuevos héroes. Creemos juntos algo legendario.

---

**¿Listo para hacer historia?** 🚀

*"Un solo commit puede cambiar el destino del código"* ✨
