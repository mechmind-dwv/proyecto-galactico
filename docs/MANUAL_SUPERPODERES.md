## ⚠️ ADVERTENCIAS CÓSMICAS

### Poderes Peligrosos (Usar con cuidado)
```javascript
// Estos poderes pueden romper la realidad
dangerousPowers = {
  deleteUniverse: true,      // ⚠️ No reversible
  alterPast: true,          // ⚠️ Paradojas temporales
  mergeDimensions: true     // ⚠️ Caos interdimensional
};
```

### Requisitos de Seguridad
- Siempre haz backup antes de usar poderes nivel 3+
- No ejecutes `bigbang` en producción
- Supervisa los loops infinitos
