# 🚀 GUÍA DE INSTALACIÓN GALÁCTICA 🚀

## ⚡ REQUISITOS PREVIOS (PODERES NECESARIOS)

### 🌟 Nivel Jedi del Código
- Node.js 18+ (o superior, del futuro si puedes)
- npm 9+ o yarn 1.22+ (o pnpm si eres rebelde)
- Git 2.35+ (para viajes en el tiempo)

### 🖥️ Configuración del Entorno
```bash
# Verifica tu nivel de poder
node --version
npm --version
git --version

# Si falta algún poder, consíguelo:
# https://nodejs.org/ (Poder Node)
# https://git-scm.com/ (Poder Git)
```

## 🔥 INSTALACIÓN BÁSICA (PARA MORTALES)

### Paso 1: Clonar el Universo
```bash
git clone https://github.com/tu-usuario/proyecto-galactico.git
cd proyecto-galactico
```

### Paso 2: Invocar las Dependencias Mágicas
```bash
npm install
# o si prefieres el lado oscuro
yarn install
```

### Paso 3: Configurar Variables de Entorno
```bash
cp .env.example .env
# Edita el archivo .env con tus secretos galácticos
```

### Paso 4: ¡DESPERTAR AL LEVIATÁN!
```bash
npm start
# ¡El monstruo cobra vida! 🔥
```

## 🌟 INSTALACIÓN AVANZADA (PARA DIOSES)

## 🚨 SOLUCIÓN DE PROBLEMAS CÓSMICOS

### Problema: "npm install falla"
```bash
# Limpia la cache del universo
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### Problema: "Puerto ocupado"
```bash
# Encuentra y destruye el proceso
lsof -ti:3000 | xargs kill -9
# O cambia a otro puerto
PORT=8080 npm start
```

### Problema: "Módulos nativos fallan"
```bash
# Reconstruye los módulos nativos
npm rebuild
# o para problemas serios
rm -rf node_modules && npm install
```
