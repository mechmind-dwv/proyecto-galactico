## 🧭 CÓMO ACTUALIZAR

### De v0.x a v1.0
```bash
# 1. Respalda tu configuración actual
cp .env .env.backup

# 2. Obtén los últimos cambios
git pull origin main

# 3. Actualiza dependencias
npm install

# 4. Corre migraciones (si las hay)
npm run migrate

# 5. ¡Disfruta de la nueva versión épica!
```
